# Notas en español

Este documento verifica el soporte de **nombres de archivo Unicode** y contenido multilingüe.

## Características verificadas

- Descubrimiento de archivos con acentos: `español`, `文档`, `日本語`
- Codificación URL por segmento en la barra de navegación
- Búsqueda dentro del contenido
- Tabla de contenidos generada a partir de los encabezados

## Ejemplo

```bash
echo "¡Hola, Ry-Mark!"
```

:::info
Los archivos se ordenan alfabéticamente; los directorios aparecen primero.
:::
