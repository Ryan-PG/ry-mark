# Style Guide

This document has **spaces in its filename** to verify that files without dashes are discovered, titled, linked and searched correctly.

## Naming rules

- Prefer kebab-case for new documents (`my-guide.md`).
- Spaces are fully supported — the manifest encodes them per URL segment.
- Unicode is supported too: see [Notes español](./Notes%20español.md).

## Linking between documents

Relative links resolve against the current document's directory:

- [Welcome](../README.md)
- [Architecture](../Engineering/Architecture.md)
- [API conventions](../Engineering/Backend/API.md)

Anchors work as well: [jump to naming rules](#naming-rules).
